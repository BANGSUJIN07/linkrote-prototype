## 1. 제품 개요

### 1.1 한 줄 정의
여러 분야의 사람이 **돌아가며** 서로를 만나고, 연결될 때마다 혜택을 받으며, 함께 프로그램과 대회를 여는 **순환형 네트워킹 커뮤니티**. `[확정]`

### 1.2 핵심 한마디
"한 분야와 소통했으면 다음 분야로 넘어간다." `[확정]`

### 1.3 이름의 뜻
연결(Link) + 돌아가기(Rotate). 분야를 돌며 연결한다는 핵심 규칙을 담은 이름. `[확정]`

### 1.4 고유 가치 제안 (UVP)
"분야를 돌아가며 연결될 때마다 혜택과 재능 교환으로 보상받는 순환 네트워킹" `[확정]`

## 2. 배경과 문제

고객이 겪는 가장 큰 불편 3가지 (린캔버스 기준).

| # | 문제 | 해결 방향 |
|---|---|---|
| P1 | 같은 분야 사람끼리만 만나서 새로운 아이디어와 협업 기회가 생기기 어렵다. `[확정]` | **로테이션**: 매주 다른 분야 라운드 + "받으려면 다른 분야에서 받는다" 규칙 |
| P2 | 네트워킹 모임은 한 번 가고 끝나기 쉽다. 계속 참여할 이유(혜택, 재미)가 약하다. `[확정]` | **연결 혜택**(스탬프→혜택), 대회, 산타 정모, 시즌 페스티벌 |
| P3 | 취업·서비스 기획을 준비하는 청년이 다른 분야와 협업한 경험을 쌓고 보여줄 방법이 마땅치 않다. `[확정]` | **번개 프로젝트**, **재능 지도**(무엇을 누구와 주고받았는지 기록) |

> 유의: 린캔버스의 "유의사항"에 따르면 P2·P3은 실제 참가자 이야기와 맞는지 아직 확인되지 않았습니다. 시범 라운드에서 인터뷰나 설문으로 검증해야 합니다.

## 3. 목표와 비목표

### 3.1 목표 (이 제품이 해야 할 일)
1. 서로 다른 분야 사람이 **강제로 섞이게** 만든다. (분야를 섞는 것이 규칙)
2. 한 번 오고 끝나지 않도록 **다시 올 이유**(혜택·놀이·재능 교환)를 만든다.
3. 참가자가 **다른 분야와 협업한 기록**(재능 지도)을 남기게 한다.
4. 처음부터 **지표를 직접 기록**해서 후원·지원사업·투자 제안의 근거로 쓴다.

### 3.2 비목표 (지금은 하지 않는 일)
- **조각의 현금 환전**: 세금·법 문제가 생길 수 있어 처음에는 하지 않음. `[확정]`
- **참가자에게 돈 받기**: 참가자에게 돈을 받지 않는 방향. `[확정]`
- **굿즈 판매를 중심 사업으로 삼기**: 보조 사업. 처음에는 참가 선물로만. `[확정]`
- **처음부터 앱/웹 플랫폼 제작**: 시범 라운드는 스프레드시트 같은 무료 도구로 조각을 직접 기록. 투자 후 제작을 제안. `[확정]`
- **민감한 개인정보 수집**: 신청서에 받지 않음. `[확정]`

## 4. 대상 사용자

### 4.1 대상
대학생과 청년. 처음 참가자는 온라인·오프라인 홍보로 모집. `[확정]`

### 4.2 처음 모을 분야
분야는 시범 라운드 반응을 보고 늘린다. `[확정]`
**정리**: 아래 4개는 제안된 후보이고, **시범 라운드는 분야 3개로 시작**한다. 운영자가 3개를 미리 고정하지 않고, **참가자가 가입할 때 자기 분야를 직접 정한다.** `[확정: 기획자 결정]`
참가자가 고른 분야가 3개를 넘으면 **참가 인원이 많은 3개 분야로 운영**한다. 운영에서 빠진 분야는 **다음번 운영으로 넘긴다.** 여기서 "다음번"은 **시범 라운드 → 탤런트 스왑 → 정식 시즌** 순서의 다음 단계다. 참가자는 가입할 때 **1~2순위 분야만 골라 우선순위를 미리 체크**하며, 인원이 같든 다르든 항상 체크한다. 인원이 같을 때는 이 우선순위로 배정한다. 인원이 다를 때는 인원이 적어 운영에서 빠진 분야를 1순위로 고른 참가자를 **2순위 분야에 배정**한다. 1순위와 2순위 분야가 **모두** 운영에서 빠져 참여하지 못하는 참가자는 **다음 기회를 기다리며 마음 돌봄 활동이나 보조 사업(굿즈)에 참여**하도록 독려하고, **다음 단계 시작 3주 전에 홍보 문자나 메일로 알린다.** 이 알림과 독려는 1·2순위가 모두 빠진 참가자에게**만** 보낸다. 1순위만 빠져 2순위 분야에 배정된 참가자에게는 "다음 단계에 1순위 분야가 열린다"는 안내를 따로 보낸다. `[확정: 기획자 결정]`

| 분야 | 설명 |
|---|---|
| 디자인·예술 | 창작, 전시, 디자인을 하는 사람들 |
| 복지·사회 | 사람과 사회를 돌보는 일을 하는 사람들 |
| 기획·스타트업 | 서비스와 사업을 기획하는 사람들 |
| 통역·번역 | 언어로 사람과 사람을 잇는 사람들 |

### 4.3 가장 먼저 쓸 사람 (얼리어답터)
취업이나 서비스 기획을 준비하며 **협업 경험이 필요한 사람**. `[제안]` (실제 참가자와 맞는지 확인 필요)

### 4.4 이용자 유형 (이 문서에서 정리)
| 유형 | 하는 일 | 비고 |
|---|---|---|
| 참가자 | 재능을 주고받고, 라운드·대회·프로젝트에 참여 | 핵심 사용자 |
| 분야 대표(앰버서더) | 분야마다 1~2명, 그 분야 사람을 모아 옴 | 유입 담당 |
| 운영자 (= 직원) | 스탬프·조각 관리, 약속 불이행·분쟁 중재, 굿즈 제작, 참가자가 기획한 마음 돌봄 활동 개최, 문자·메일 알림 발송 | **직원은 창업자(기획자) 본인이며, 본인도 급여를 받는다. 처음에는 별도 직원을 채용하지 않는다.** `[확정: 기획자 결정]` 이후 인원이 늘면 따로 채용할지 검토 |
| 제휴처 | 공간·음료·혜택을 제공하는 카페, 공간, 대학, 복지관 등 | 후원·협찬 |
| 후원사·투자자 | 페스티벌에 초대되어 성과를 확인 | 자금원 |

## 6. 핵심 운영 규칙

### 규칙 1. 로테이션 (돌아가며 만나기) `[확정]`
- 4주를 한 시즌으로 하고, 매주 다른 분야 라운드를 연다.
- 시즌이 끝나면 "내가 만난 분야 지도"가 완성된다.

### 규칙 2. 연결 혜택 `[확정]`
- 새 분야 사람과 연결될 때마다 스탬프를 받는다.
- 스탬프가 모이면 혜택으로 바꾼다. 비용 부담이 적은 것부터 시작: **공간 대여, 전시 초대, 재능 교환**.

### 규칙 3. 번개 프로젝트 (자유 프로그램) `[확정]`
- 서로 다른 분야 2~3팀이 모여 2주짜리 미니 프로그램을 직접 연다.
- 예: 디자이너, 복지 전공자, 전시 기획자가 함께 만드는 "지속가능한 환경 만들기 프로젝트".
- 플랫폼이 장소를 연결하거나 소액을 지원한다.

### 규칙 4. 받으려면 다른 분야에서 받는다 (탤런트 스왑의 핵심) `[확정]`
- 내 분야 재능은 같은 분야 사람에게 쓸 수 없고, **다른 분야에서만** 받을 수 있다.
- 그래서 조각을 쓰는 행동이 곧 로테이션 네트워킹이 된다.
- 차별점 설명: 재능을 시간으로 바꿔 주고받는 "시간은행"은 이미 있는 개념이므로, 차별점은 **"섞이게 만드는 규칙"**이다.

## 8. 사용자 여정

### 8.1 참가자 기본 흐름
1. **가입**: 분야를 고르고, 재능 메뉴판(내가 줄 수 있는 것을 30분 단위로)을 적는다. 가입 선물 3조각을 받는다.
2. **라운드 참여**: 매주 열리는 다른 분야 라운드에서 새 분야 사람을 만난다. 연결될 때마다 스탬프를 받는다.
3. **재능 교환**: 도와주세요 카드를 올리거나, 다른 분야 사람의 카드에 응답한다. 첫 교환은 30분 한 번만.
4. **교환 확정 후 연락처 공개**: 교환이 확정된 뒤에만 연락처가 공개된다.
5. **고마움 카드**: 교환이 끝나면 서로 구체적인 한 줄을 적는다. 조각이 정산된다.
6. **혜택·대회·프로젝트**: 스탬프와 조각으로 혜택 교환, 대회 참가, 번개 프로젝트 합류.
7. **시즌 종료**: 내가 만난 분야 지도와 재능 지도를 확인하고, 시즌 페스티벌에서 결과를 공개한다.

### 8.2 시즌 흐름 (프로그램 구성)
"가볍게 자주 → 대회로 모으고 → 정모로 깊게 → 페스티벌로 공개" `[확정]`

| 단계 | 프로그램 | 내용 | 역할 |
|---|---|---|---|
| 1 | 일상 모임 | 질문 교환(명함 대신 "요즘 막힌 것 한 가지" 카드), 블라인드 첫 만남(직업 공개 전 10분 대화), 한 시간 전문가 번개 | 가볍게 자주 만나기 |
| 2 | 대회 | 섞어서 팀 짜는 대회(서로 다른 분야 4명 무작위 팀), 연결 점수 대회(새 분야 연결 수로 점수), 릴레이 대회(A→B→C 분야가 이어서 완성), 문제 의뢰 대회(동네 가게·복지관의 실제 고민 해결) | 참가자 모으고 협업 만들기 |
| 3 | 연말 산타 정모 | 다른 분야 사람끼리 마니또(익명 산타)를 맺고 재능·손편지 선물 교환, "올해의 산타상" 시상 | 관계 깊게 만들기, 후기 콘텐츠 |
| 4 | 시즌 페스티벌 | 시즌 동안 나온 프로젝트 전시·시상, 후원사·투자자 초대 | 성과 공개 |

- **연결 성사 건수의 기준**: 두 가지 기준을 **항상 함께 계산해서 보여 주고**, 대표 지표로 쓸 기준은 설정에서 고른다(기본값은 재능 교환). `[확정: 기획자 결정]`
  - **재능 교환 연결 수**: 운영자가 확정한 교환(확정·완료·정산) 1건이 1연결이다. 같은 분야의 한 사람이 다른 분야 사람과 2번 교환하면 2건으로 센다. (응답만 한 교환, 취소, 노쇼는 세지 않는다는 점은 프로토타입의 가정)
  - **라운드 스탬프 연결 수**: 운영자가 스탬프 화면에 기록한, 서로 다른 분야 두 사람의 라운드 만남 수. 재능 교환 없이 만나기만 한 경우도 포함한다.
  - 두 숫자는 서로 다르다. 예: 같은 두 사람이 2번 교환하면 재능 교환 2건이지만 스탬프는 새로운 사람 기준이라 1개다.
- **다시 요청한 사람 수의 기준**: 재능 교환을 **1번 이상 마친 뒤, 도와주세요 카드를 다시 올린 사람**의 수. 교환을 마친 사람은 재능을 준 사람과 받은 사람 모두 포함한다. `[확정: 기획자 결정]` (자료에는 이 지표의 정의가 없어서 정했고, 분야 변경 희망과는 무관하다.)

**참가자 구분 기록** `[제안]`: 단계마다 참가자가 바뀔 수 있으므로(11장), 지표 1~5는 "이어서 온 사람"과 "새로 온 사람"으로 나눠 함께 기록한다(F-62). 특히 재방문율은 "앞 단계 참가자 중 다시 온 사람 ÷ 앞 단계 참가자 전체"로 계산해야 신규 모집 때문에 낮아 보이는 일을 막는다. 계산식은 이 문서에서 정리한 제안이며, 자료에 없다.

- 현금 지급이 가능한지는 세금·법 문제가 있어 전문가·공식 기관 확인이 필요하다.

### 12.2 투자 유치 준비 3가지 `[확정]`
1. **증명할 지표**: 가입자 수, 재방문율, 연결 성사 건수, 번개 프로젝트 개수를 직접 기록.
2. **투자금 사용 계획**: 후보는 운영 인력, 행사·대회 비용, 혜택 비용, 플랫폼 제작. 금액은 1회 라운드를 열어 실제 비용을 확인한 뒤 채움.
3. **성과를 보여줄 자리**: 시즌 마지막 페스티벌에 투자자·후원사 초대.

진행 단계: 1단계 라운드 1~2회로 지표 쌓기 → 2단계 정부 지원금 공고에서 대상·조건 확인 → 3단계 쌓은 지표로 투자 제안 준비.

### 12.3 정부 지원금 준비 `[확정]`
- 자격 확인: 나이, 사업자 등록 여부, 창업 몇 년 차까지 지원하는지를 공고문에서 확인.
- 찾을 곳: 창업은 K-Startup, 청년은 온통청년·지자체 청년센터, 문화예술은 한국문화예술위원회·지역 문화재단 공고.
- 현재 열려 있는 공고는 자료에서 확인하지 못했음.
- 공고 취지에 맞춰 "청년 교류", "문화예술과 복지 연계", "지역 연계" 중 맞는 면을 앞세워 작성.

   - 구체적인 활동 목록(어떤 취미·활동을 할지)과 언제·어디서·몇 명이 하는지
   - 직원이 열어줄 때 드는 비용을 누가 부담하는지
   - 참가자가 기획안을 내는 방법과 직원이 승인하는 기준
3. **연락처 수집 방식**: 문자·메일 알림(F-14)을 위해 연락처와 수신 동의를 받아야 한다. 신청서에 민감한 정보를 받지 않는 원칙(F-04)과 함께 어떤 항목까지 받을지 확인 필요
4. **조각 규칙의 최종 숫자**: 가입 선물, 보너스, 마이너스 한도, 소멸 비율
5. **수입 금액**: 후원·협찬, 의뢰, 지원금, 투자 모두 미정
6. **투자금 사용 계획의 금액**: 시범 라운드 후 채움
7. **산타 정모 수익의 기부 비율**
8. **굿즈**: 사업자 등록·통신판매 절차, 기존 디자인 사업과 합칠지 따로 둘지
9. **번개 프로젝트의 소액 지원**: 금액과 선정 기준
10. **운영자 확대 시점**: 운영자(직원)는 창업자 본인이므로, 참가자가 늘 때 언제 따로 채용할지(기준 인원 등)
11. **참가자 인터뷰**로 P2·P3 문제, 얼리어답터 설명, 재능 지도의 가치를 검증
12. **창업자 급여액과 재원**: 창업자도 급여를 받기로 했으나(13장), 얼마를 받을지와 어떤 돈으로 줄지(투자금·지원금 등. 지원사업은 인건비로 쓸 수 있는지 공고문 확인 필요)는 미정

## 19. 로컬 웹 프로토타입에서 정한 규칙

로컬 웹 프로토타입(설치 없이 `index.html`을 열어 시험하는 버전)을 만들면서 정해진 규칙입니다. PRD와 프로그램이 서로 다르지 않도록 여기에 적습니다.

### 19.1 기획자가 직접 정한 것 `[확정: 기획자 결정]`
| 항목 | 내용 |
|---|---|
| 새 분야 첫 교환 보너스 | 재능을 준 사람과 받은 사람 둘 다 +1조각 |
| 대회 팀 | 4명. 서로 다른 분야가 되도록 섞는다. 운영 분야가 3개뿐이면 한 분야가 겹칠 수 있고, 분야를 늘리면 겹치지 않는다 |
| 분야 배정 | 참가자가 1~2순위를 미리 체크 → 1순위 인원이 많은 3개 분야 운영 → 1순위가 빠지면 2순위 배정 → 둘 다 빠지면 대기 |
| 연결 성사 건수 | 두 기준(재능 교환 연결 수 / 라운드 스탬프 연결 수)을 항상 함께 계산하고, 대표 지표 기준은 설정에서 선택(기본 재능 교환). 재능 교환 기준은 확정된 교환 1건 = 1연결(같은 두 사람이 2번 교환하면 2건) |
| 다시 요청한 사람 수 | 교환을 1번 이상 마친 뒤 도와주세요 카드를 다시 올린 사람 (준 사람·받은 사람 모두 포함) |
| 비워 둔 값 | 혜택 1개에 필요한 스탬프 수, 노쇼 차감 조각 수는 아직 정하지 않았다. 비어 있으면 해당 기능 버튼이 꺼진다 |

### 19.2 프로토타입이 가정한 것 `[가정: 기획자가 괜찮다고 함]`
기획 문서에 없어서 프로토타입을 만들며 임시로 정한 규칙입니다. 기획자가 검토해 "괜찮다"고 했지만, 시범 라운드에서 실제 운영해 보고 다르면 바꿔야 합니다. (연결 성사 건수는 기획자가 따로 정해 19.1로 옮겼습니다.)

| 항목 | 프로토타입의 가정 |
|---|---|
| 교환 흐름 | 응답 → 확정(운영자) → 완료(운영자) → 고마움 카드(양쪽) → 정산(운영자) |
| 같은 카드의 다른 응답 | 한 응답이 확정되면 같은 카드의 다른 응답은 자동 취소. 확정된 교환을 취소하면 카드가 다시 "열림" |
| 첫 교환 | 확정·완료·정산·노쇼 교환이 한 번도 없는 사람의 교환. 주는 사람과 받는 사람 중 한 명이라도 첫 교환이면 30분(1조각)만 가능 |
| 조각 수 상한 | 만들지 않았다(1 이상의 정수만 가능). 마이너스 한도만 적용 |
| 분야 배정 동점 | 운영 분야 경계(3번째와 4번째)가 같으면 자동으로 정하지 않고 운영자가 선택. 1순위 인원이 0명인 분야는 후보에서 제외 |
| 노쇼 | "확정" 상태의 교환에서만 처리 가능. 노쇼가 되어도 카드는 다시 열리지 않음 |
| 스탬프 | 서로 다른 분야의 새로운 사람마다 1개. 재능 교환을 해도 자동으로 주지 않고 운영자가 기록 |
| 분야 선택 | 후보 분야 중에서 고르거나 "목록에 없으면 직접 적기" |
| 시험 전 상태 | 샘플 참가자는 "미배정" 상태로 만들어지고, 분야 배정을 확정해야 교환·팀 짜기가 가능 |

### 19.3 프로토타입의 한계
- 데이터는 사용하는 컴퓨터의 브라우저에만 저장된다(여러 사람이 각자 휴대폰으로 쓸 수 없음). 정기적으로 백업 파일을 내보내야 한다.
- 로그인이 없고, 운영자 한 명이 "지금 보는 사람"을 바꿔 가며 모든 역할을 시험한다.
- 시험용이므로 가짜 연락처만 쓴다.
- 이번 범위에서 만들지 않은 기능: F-05, 13, 15, 16, 25(시즌 종료 소멸), 28, 29, 40, 41, 43, 44, 50~52, 굿즈 판매.
