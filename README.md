# 링크로테 (LinkRote) 로컬 웹 프로토타입

여러 분야의 사람이 돌아가며 만나고, 재능을 '조각'으로 주고받는 순환 네트워킹 서비스의 **시범 라운드 시험용 프로토타입**입니다.
국민대학교 AX-Startup 부트캠프 2기 교육 실습으로 만들었습니다.

## 열어 보기
- 배포된 주소(Vercel)에서 바로 열거나, 이 폴더의 `index.html`을 더블클릭하면 열립니다. 설치할 것이 없습니다.
- 규칙 자동 점검: `test.html`을 열면 통과/실패 목록이 나옵니다.
- 처음 쓸 때: 운영자 화면 **A8 설정·백업 → 샘플 데이터 넣기 → A2 분야 배정 → 배정 실행 → 확정** 순서로 시작하세요.

## 꼭 알아 두세요
- 시험용입니다. **실제 이름, 연락처, 주민등록번호, 계좌번호 같은 민감한 정보는 넣지 마세요.** 가짜 이름과 가짜 연락처만 쓰세요.
- 입력한 데이터는 서버에 저장되지 않고 **사용하는 사람의 브라우저에만** 저장됩니다. 브라우저 기록을 지우면 사라집니다. A8의 내보내기로 백업할 수 있습니다.
- 로그인이 없고, 위쪽 "지금 보는 사람" 선택 상자로 운영자와 참가자 역할을 바꿔 가며 시험합니다.

## 구성
| 위치 | 내용 |
|---|---|
| `index.html` | 화면 틀과 메뉴 |

| `docs/PRD.md` | 기획 문서(PRD) |
