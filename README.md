# 링크로테 (LinkRote)

여러 분야의 사람이 돌아가며 서로를 만나고, 연결될 때마다 혜택을 받으며, 함께 프로그램과 대회를 여는 **순환형 네트워킹 커뮤니티**입니다.
국민대학교 AX-Startup 부트캠프 2기 교육 실습으로 만든 MVP입니다.

## 구성
| 위치 | 내용 |
|---|---|
| `index.html`, `css/`, `img/` | 서비스 소개·사전 신청 페이지 (첫 화면) |
| `prototype/` | 시범 라운드 규칙을 시험해 보는 프로토타입 (운영자용 도구) |
| `prototype/test.html` | 프로토타입 규칙 자동 점검 페이지 |
| `링크로테_MVP.html` | 소개·사전 신청 페이지를 한 파일로 합친 버전 |
| `docs/링크로테_PRD_v6.md` | 기획 문서(PRD) 최신본 |
| `docs/신청폼_질문.md` | 구글 폼 질문 목록과 만드는 방법 |
| `docs/링크로테_운영시트양식.xlsx` | 시범 라운드 운영 시트 양식 (수식·드롭다운 포함) |

## 열어 보기
- 배포된 주소(Vercel)에서 바로 열거나, `index.html`을 더블클릭하면 열립니다. 설치할 것이 없습니다.
- 프로토타입은 `prototype/index.html`을 엽니다. 처음에는 운영자 화면 **A8 설정·백업 → 샘플 데이터 넣기 → A2 분야 배정 → 배정 실행 → 확정** 순서로 시작하세요.

## 꼭 알아 두세요
- 프로토타입은 시험용입니다. **실제 이름, 연락처, 주민등록번호, 계좌번호 같은 민감한 정보는 넣지 마세요.** 가짜 이름과 가짜 연락처만 쓰세요.
- 프로토타입에 입력한 데이터는 서버에 저장되지 않고 **사용하는 사람의 브라우저에만** 저장됩니다. 브라우저 기록을 지우면 사라집니다.
- 소개 페이지의 폰트와 신청 폼 연결은 인터넷이 연결되어 있어야 합니다.
